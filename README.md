# stock-screener

A 股涨停股自动筛选工具，基于知名游资「北京炒家」首板战法和「陈小群」龙头战法的策略框架，盘后自动抓取行情数据并生成筛选报告。

## 策略框架

### 北京炒家 — 首板打板
- 流通市值 20-100 亿
- 股价 < 20 元
- 换手率 2-25%
- 板块效应优先（同概念 ≥3 只涨停）
- 排除一字板、尾盘偷袭板、机构重仓股

### 陈小群 — 龙头战法
- 识别强势板块（≥3 只涨停）
- 按换手率 + 市值 + 低价三因子排定龙头座次
- T 字不破再涨停的 T 字战法
- 龙二波战法

## 使用方式

### 手动运行
```bash
python stock_screener.py
```

### 定时任务（Hermes Cron）
已在 Hermes Agent 中配置为交易日 16:00 自动运行，报告自动投递到聊天会话。

## 数据来源
新浪财经行情 API（实时）
